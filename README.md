# Modern Minimalist To-Do App

A clean, responsive, and fully functional vanilla JavaScript To-Do Web Application.

## ✨ Features

- **Task Management**: Create, view, complete, edit (inline with double-click or edit button), and delete tasks.
- **Priority Levels**: Assign `High`, `Normal`, or `Low` priority tags with distinct badges.
- **Categories**: Organize tasks by category (`Personal`, `Work`, `Shopping`, `Health`, `Other`) and filter easily with fast category chips.
- **Due Dates**: Select due dates with visual badges and automatic **Overdue** alerts for late pending tasks.
- **Instant Search**: Real-time filtering by task title.
- **Status Filter**: Switch smoothly between `All`, `Active`, and `Completed`.
- **Progress Tracking**: Real-time progress bar showing the percentage and count of finished tasks.
- **Live Filter Counters**: Each status tab (`All`/`Active`/`Done`) displays a real-time task count.
- **Quick Due Dates**: One-tap **Today** / **Tomorrow** shortcuts plus smart due badges (`Today`, `Tomorrow`, *n* • Overdue).
- **Confetti Celebration**: A playful confetti burst fires when you complete a task — bigger when you clear everything.
- **Dark Mode & Light Mode**: Seamless theme switcher that respects system preferences and persists user preference.
- **Persistent Storage**: Uses `localStorage` so tasks and settings remain saved across sessions.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Modern Glass UI**: Ambient gradient glows, glassmorphism, color-coded categories, gradient progress bar, and hover-reveal row actions.

## 🚀 Getting Started

1. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
2. Or serve it using an extension like VS Code **Live Server**.
